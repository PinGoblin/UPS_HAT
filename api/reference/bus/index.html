    I²C bus and errors¶

    This module provides I²C access and exposes the library's exception classes.

    Any object with MicroPython's machine.I2C memory methods can carry the I²C bus:

    readfrom_mem(addr, reg, nbytes) -> bytes
writeto_mem(addr, reg, buf)

    On a Raspberry Pi (CPython), LinuxI2C talks to /dev/i2c-N directly and needs no extra packages.

    I2CBus ¶

    Bases: Protocol

    Anything with MicroPython machine.I2C memory methods (type-checking only).

    UPSError ¶

    Bases: Exception

    Base class for every error raised by this library.

    DeviceNotFound ¶

    Bases: UPSError

    A chip did not answer on the I²C bus, or reported the wrong ID.

    BusError ¶

    Bases: UPSError

    An I²C transfer failed.

    NotSupported ¶

    Bases: UPSError

    The operation is not possible on this board or in this environment.

    Raised, for example, by the power-off methods on a board built without the ship FET.

    LinuxI2C ¶

    LinuxI2C(bus: int = 1)

    machine.I2C-compatible wrapper for Linux /dev/i2c-N.

    Uses plain read()/write() on the character device, so it needs no third-party package. The Raspberry Pi header I²C (pins 3 and 5) is bus 1.

    Can be used as a context manager, which closes the device on exit.

    Parameters:

    Name Type Description Default
    bus int

    I²C bus number.

    		 1

    Raises:

    Type Description
    OSError

    The device file does not exist or cannot be opened (I²C disabled, or no permission: run as root or join the i2c group).
    Example 
    from ups_hat import LinuxI2C, BQ25798

with LinuxI2C(1) as i2c:
    print(BQ25798(i2c).read_adc())

    Name Type Description Default
    bus int

    		 1
