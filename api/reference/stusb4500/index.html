    STUSB4500 USB-C PD¶

    A low-level driver for the ST STUSB4500 USB-C PD sink controller (U1, I²C address 0x28).

    The register map and NVM sequence follow ST's public register map and reference software (github.com/usb-c/STUSB4500) and SparkFun's STUSB4500 library.

    The negotiated contract (RDO) gives the source PDO position and the current. The source's list of voltages is only on the bus for about 3 ms during negotiation, so the contract voltage is best taken from the charger's VBUS ADC.

    renegotiate ¶

    renegotiate() -> None

    Send a PD soft reset so the source re-offers and the sink re-requests.

    VBUS normally stays up, but the source may briefly drop to 5 V.

    software_reset ¶

    software_reset() -> None

    Reset the whole chip, as the RESET pin does.

    The port detaches and VBUS falls to 5 V or off.
