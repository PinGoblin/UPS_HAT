    BQ25798 charger¶

    This module provides a low-level driver for the TI BQ25798 buck-boost charger (U2, I²C address 0x6B).

    Register map: TI datasheet SLUSDV2. 16-bit registers are most significant byte first. Voltages are in volts, currents in amps and temperatures in °C unless the name ends in _mv, _ma or _raw.

    The UPS HAT+ does not use OTG (it would drive VBUS on a sink-only USB-C port), the ACFET/RBFET input switches or MPPT, so this driver deliberately offers no way to turn them on. TS has no NTC on Rev D (fixed 60 % divider); ts_ignore is exposed for completeness and is not used by UPS.

    CHG_STAT module-attribute ¶

    CHG_STAT: Tuple[str, ...] = ('not charging', 'trickle charge', 'pre-charge', 'fast charge (CC)', 'taper charge (CV)', 'reserved', 'top-off', 'charge done')

    Charge state names, indexed by the 3-bit charge state code.

    SDRV_IDLE module-attribute ¶

    SDRV_IDLE: int = const(0)

    SDRV_CTRL code: idle.

    SDRV_SHUTDOWN module-attribute ¶

    SDRV_SHUTDOWN: int = const(1)

    SDRV_CTRL code: shutdown mode (wakes only on adapter).

    SDRV_SHIP module-attribute ¶

    SDRV_SHIP: int = const(2)

    SDRV_CTRL code: ship mode (wakes on SW1 or adapter).

    SDRV_SYSTEM_RESET module-attribute ¶

    SDRV_SYSTEM_RESET: int = const(3)

    SDRV_CTRL code: system power reset.

    BQ25798 ¶

    BQ25798(i2c: I2CBus, address: int = ADDRESS, check: bool = True)

    Register-level driver for the BQ25798.

    Every setting the board can safely use is a property; field() and set_field() give raw access to anything else. Setters clamp values to the chip's range and round to the nearest step.

    All methods and properties raise BusError if a transfer fails.

    Parameters:

    Name Type Description Default
    i2c I2CBus

    Bus object with readfrom_mem() and writeto_mem().

    		 required
    address int

    7-bit I²C address.

    		 ADDRESS
    check bool

    Check the part number in register 0x48.

    		 True

    Raises:

    Type Description
    DeviceNotFound

    check is true and the part number is not the BQ25798's.
    BusError

    The chip did not answer.

    ts_ignore property writable ¶

    ts_ignore: bool

    Ignore the TS pin (TS_IGNORE, register 0x18 bit 0).

    True makes the charger behave as if at room temperature: no JEITA limits and no cold/hot stop. Reset to False by power-on reset, REG_RST and the I²C watchdog, so re-apply it after any charger reset. Not used on Rev D, whose TS divider already reads as normal temperature.
