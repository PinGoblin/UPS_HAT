    UPS and Snapshot¶

    This module exposes a high-level interface to the UPS HAT+ (Rev D and later).

    UPS is the class most programs use. Each poll() returns a Snapshot.

    FACTORY_PDOS module-attribute ¶

    FACTORY_PDOS: Tuple[Tuple[float, float], ...] = ((5.0, 3.0), (9.0, 3.0), (15.0, 3.0))

    USB PD sink profiles written in the factory, as (volts, amps): 5 V / 3 A, 9 V / 3 A and 15 V / 3 A.

    CHARGE_VOLTAGE_RANGE module-attribute ¶

    CHARGE_VOLTAGE_RANGE: Tuple[float, float] = (7.0, 8.4)

    Allowed pack charge voltage (V): 7.0 to 8.4 (3.5 to 4.2 V per cell).

    CHARGE_CURRENT_MAX module-attribute ¶

    CHARGE_CURRENT_MAX: float = 3.0

    Highest charge current (A).

    INPUT_CURRENT_MAX module-attribute ¶

    INPUT_CURRENT_MAX: float = 3.0

    Highest USB-C input current limit (A).

    OUTPUT_POWER_LIMIT module-attribute ¶

    OUTPUT_POWER_LIMIT: float = 25.5

    5.1 V output rating (W): 5.1 V × 5 A.

    Values are None when the chip that provides them did not answer.

    UPS ¶

    UPS(i2c: Optional[I2CBus] = None, cells_parallel: int = 1, cell_capacity_mah: float = 3000.0, charge_voltage: float = 8.2, charge_current: Optional[float] = None, ship_fet: bool = True, state_file: Optional[str] = None, low_battery_soc: float = 5.0, low_battery_voltage: float = 6.2, auto_configure: bool = True, protect: bool = True, pi_monitor: bool = True, bus: int = 1)

    The UPS HAT+.

    Creating the object connects to both chips and, with auto_configure, applies the charger settings. Call poll() every 1–5 s.

    Parameters:

    Name Type Description Default
    i2c Optional[I2CBus]

    Object with MicroPython machine.I2C memory methods. Defaults to /dev/i2c-<bus> on Linux; required on MicroPython.

    		 None
    cells_parallel int

    1 = 2S1P (two cells), 2 = 2S2P (four cells).

    		 1
    cell_capacity_mah float

    Rated capacity of one cell (mAh).

    		 3000.0
    charge_voltage float

    Pack charge voltage (V), clamped to 7.0–8.4 V. 8.2 V (4.10 V per cell) gives long cell life.

    		 8.2
    charge_current Optional[float]

    Charge current (A), clamped to 0.1–3.0 A. Defaults to 1.5 A for 2S1P and 2.0 A for 2S2P.

    		 None
    ship_fet bool

    The board has the SDRV ship FET fitted. Needed for power_off() and ship mode.

    		 True
    state_file Optional[str]

    JSON file that keeps learned battery data between runs. None keeps it in memory only.

    		 None
    low_battery_soc float

    On battery, should_shutdown becomes true at or below this state of charge (%).

    		 5.0
    low_battery_voltage float

    On battery, should_shutdown becomes true at or below this pack voltage (V).

    		 6.2
    auto_configure bool

    Apply the charger settings now, and re-apply them if the charger resets.

    		 True
    protect bool

    Stop charging while the battery reads like a wiring fault, and resume when it clears.

    		 True
    pi_monitor bool

    Read the Pi 5 supply state through vcgencmd when available.

    		 True
    bus int

    Linux I²C bus number, used when i2c is None.

    		 1

    Raises:

    Type Description
    ValueError

    cells_parallel is not 1 or 2.
    NotSupported

    i2c is None on MicroPython.

    Attributes:

    Name Type Description
    charger BQ25798 | None

    Charger driver, None while the chip is not answering.
    pd STUSB4500 | None

    USB-C controller driver, None while it is not answering.
    battery BatteryMonitor

    State-of-charge, capacity and resistance model.
    pi PiPower | None

    Pi 5 supply monitor, None if unavailable.
    Example 
    from ups_hat import UPS

ups = UPS(cells_parallel=2, cell_capacity_mah=2500, state_file="/var/lib/ups-hat/state.json")

@ups.on_fault
def alert(fault):
    print(fault)

ups.run(interval_s=2)

    configure ¶

    configure() -> None

    Apply the board's charger settings. Safe to call at any time.

    Turns the charger watchdog off, the ADC on (continuous, 15-bit) and discharge-current sensing on; sets the charge voltage and current; sets SFET_PRESENT when the ship FET is fitted; and restores the charge-enable state.

    Raises:

    Type Description
    DeviceNotFound

    The charger is not answering.
    BusError

    An I²C transfer failed.

    power_off ¶

    power_off(low_battery: Optional[bool] = None) -> str

    Final step of a Pi shutdown.

    Call from the systemd-shutdown hook on power-off or halt, never on reboot.

    Situation Action Returns
    No adapter Ship mode: the board goes dark. "ship"
    Adapter, low-battery shutdown System reset, so the Pi boots on mains. "reset"
    Adapter, user shutdown Nothing: the Pi halts, the board stays on. "none"

    Parameters:

    Name Type Description Default
    low_battery Optional[bool]

    This is a low-battery shutdown. None uses what the last poll() found.

    		 None

    Returns:

    Type Description
    str

    "ship", "reset" or "none".

    Raises:

    Type Description
    NotSupported

    Ship mode or reset is needed but the board has no ship FET.
    DeviceNotFound

    The charger is not answering.

    poll ¶

    poll() -> Snapshot

    Read everything, update the battery model and diagnose.

    Call every 1–5 s. Each call reads the charger ADC, status, faults and latched flags and the USB-C status; updates the battery model; re-applies the charger settings if the charger has reset; evaluates every fault rule; fires the callbacks; and saves the state file at most every 5 minutes.

    A chip that does not answer is reported as a fault (BUS_CHARGER_MISSING or BUS_PD_MISSING) rather than raised.

    Returns:

    Type Description
    Snapshot

    The new snapshot.
