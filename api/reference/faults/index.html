    Faults¶

    Fault codes reported by UPS.

    Each fault has a stable string code (safe to log or match on), a severity, the source it came from, a one-line message and advice for the user. The full list is CATALOGUE; the Fault codes page shows it as a table.

    Source Meaning
    charger Read from BQ25798 registers.
    pd Read from STUSB4500 registers.
    bus An I²C device did not answer.
    inferred Worked out from measurements over time: a strong hint, not proof.
    pi Read from the Raspberry Pi 5 firmware (vcgencmd).

    INFO module-attribute ¶

    INFO: int = 0

    Severity 0: information, no action needed.

    WARNING module-attribute ¶

    WARNING: int = 1

    Severity 1: needs attention.

    CRITICAL module-attribute ¶

    CRITICAL: int = 2

    Severity 2: needs action now.

    Fault ¶

    Fault(code: str, data: Optional[Dict[str, Any]] = None, transient: bool = False, since: Optional[float] = None)

    One active or transient fault.

    The severity, source, message and advice come from CATALOGUE. An unknown code is treated as a warning with source inferred.

    Parameters:

    Name Type Description Default
    code str

    Fault code, for example "BAT_LOW".

    		 required
    data Optional[Dict[str, Any]]

    Measurements that explain the fault, for example {"soc": 12.5}.

    		 None
    transient bool

    The fault appeared and cleared between two polls.

    		 False
    since Optional[float]

    Monotonic time (s) when the fault first became active.

    		 None

    Attributes:

    Name Type Description
    code str

    Fault code.
    severity int

    0 = info, 1 = warning, 2 = critical.
    source str

    charger, pd, bus, inferred or pi.
    message str

    One-line description.
    advice str

    What the user should do; may be empty.
    data dict

    Measurements that explain the fault.
    transient bool

    The fault came and went between two polls.
    since float | None

    Monotonic time (s) when it became active.

    severity_name property ¶

    severity_name: str

    Severity as text: "info", "warning" or "critical".

    to_dict ¶

    to_dict() -> Dict[str, Any]

    Convert to a JSON-serialisable dictionary.

    Returns:

    Type Description
    Dict[str, Any]

    The fault's attributes, with the severity as text.
